# Minstrel Studio

Free worldbuilding and writing software for novelists. Build your world — pages, calendars, maps, relationship maps — then write your manuscript in the same place. Your work stays on your own computer.

## Download

Get the latest Windows installer from the [Releases page](../../releases/latest) (choose the file ending in `Setup.exe`).

## Report a bug or suggest a feature

Open an [issue](../../issues/new). A plain description of what happened is all that is needed.

## Website

The project page is published with GitHub Pages from `index.html` in this repository.
